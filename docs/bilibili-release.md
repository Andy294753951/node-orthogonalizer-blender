## 视频简介

节点一多，连线就容易变成一团。Node Orthogonalizer 可以自动把 Blender 节点连线整理成水平、垂直的 90° 直角线路，让材质、合成器和几何节点网络更容易阅读和维护。

本期版本为 2.0.0，重点适配 Blender 5.2，并测试了：

- 着色器节点和 MMD 模型材质节点；
- 合成器节点；
- Geometry Nodes；
- Bake 节点的几何、数值、矢量动态插口；
- 复杂节点场景下的自动整理。

### 使用方法

安装插件后，自动整理默认开启。移动节点或修改连线后，插件会等待布局稳定并自动处理。

也可以在节点编辑器中按 `Shift + ,` 手动执行，或按 `F3` 搜索 **Node Orthogonalize**。
